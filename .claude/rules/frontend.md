## Frontend Conventions

Frontend knowledge docs live in `.knowledge/frontend/`:

- **Component library**: `.knowledge/frontend/index.md` — UI component overview (Radix UI + shadcn/ui + Tailwind).

Read the relevant knowledge doc before building or modifying frontend code.
