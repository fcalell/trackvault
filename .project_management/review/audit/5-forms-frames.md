## 2. Fixes ranked (stack cleaned vs cost)

1. Move the audio vocabulary (player words, `waveform` size, `WAVEFORM_*`/`PLAYER_*` variants, `Track`/`Peaks`/`Marker`, `./player`, `./waveform`, the DESIGN.md components, Slider `bare/said`, `lib/ink.ts`) to an opt-in plugin (items 21-24). Largest cleanup: every consumer's required `words` shrinks and the contract stops describing a music player. Cost to TV: import paths and one plugin entry in `stack.config.ts`; the Shell's dock would mount through a slot. Owned by the player and Waveform auditors, shared files here.
2. Treat an untouched secret as absent in `make` (item 3a). One condition in form/index.tsx; no TV change; closes a silent wipe in submit-mode forms.
3. Call `onChange` once with the first input (item 1). A few lines; TV's edit-rule preview stops showing a stale or empty rule on open.
4. Neutralise stack's own fixtures and doc examples (items 26, 27): camelot/crates fixtures, rules.md examples. No code; no TV cost.
5. Add BarChart to structure.md rule 7 with the reason, and comment `useWidth` (item 14). Docs only.
6. Drop `read` from the sheet Section or give it a real second-read caller (item 9). Small type change; TV may remove `read=` where it repeats `items`.
7. Parameterise `lift`'s `options` key (item 4). Small, internal.
8. Give `Sheet after` a stack caller (item 2) and a saved-secret showcase case (item 3a), so the screens run covers what only TV exercises now.

## 3. Leave as is

- `Form onChange`, `Sheet after`, `secret` with its masked hint and Remove, field `description` as a `Datum`: general patterns built from the existing `Datum`/selection model, no TV noun in any prop name.
- Lifted act and option text (`Offered`, `lift`, `ACT_TEXT`, `OPTION_TEXT`): used by stack's showcase (releases.tsx, usage.tsx) as well as TV.
- Stats cell frame, BarChart `label`: stack showcase routes and frames cover both; the shape is a generic bucketed axis and a per-cell frame.
- `Text` `kind`: fixes a lint false positive for every Biome consumer.
- Section `groups` as a `Datum`, `PicksLine`, `scrolled`/`useReach`: each removes a repeated line or a manual press, with a general shape.
- fonts.ts `local()` aliases and `isFallbackFace`: needed for Linux screen runs; no app knowledge.
- Banner's "draws nothing while the sentence waits": keep, but record the shift exception (item 6).
- Pane/Section head and Button `tabIndex`, Gate `description`: small, general.
