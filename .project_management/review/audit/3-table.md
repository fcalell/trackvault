## 2. Fixes ranked (clean-up gained / cost)
1. Reword the Table's Space/player sentence (T:1205, R Table comment, rules.md:260, reference.md:63-64). Removes the only place the Table's text knows another component. Zero cost.
2. `columnsKey` by label only (LS:659). Fixes the lost-choice-on-column-change bug and the doc contradiction. Zero cost; the viewer's saved choices reset once.
3. Phone parity of the shared Table roster entry: either native accepts `TablePick`, `row.act/more` (R:1715-1727 lists props for both), or R marks them web-only like `drag`/`reorder`. Small roster edit; no TV change (phone app uses `TableChoice` today).
4. Optional: name or doc the 8-column threshold as the stack's fold rule, nothing else.

## 3. Leave as is
Columns menu and `hidden`, figure widths, the cell cursor and its pure `moveCursor`/`rangeIds`/`pageRows`, range ticks, `Chooser`/`Picked`/`TablePick`, window rows and `pagesCovering`, sort through the input, `row.act/more`, `onEdit`, `useWide`. Each is data-driven, carries no TV noun, has a stack caller (showcase frames/table.tsx, requests.tsx) besides TV, and is documented. TV composes its player through `row.act` (library.tsx:295-312) and `windowQueue`, so the Table does not know the player. Nothing in the Table family needs removing.
